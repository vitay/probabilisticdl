Softmax classifier for discrete distributions

Kullback-Leibler divergence in machine learning showed that any model with a probabilistic interpretation, fitted to data by maximum likelihood, minimizes the KL divergence between the data and the model. This chapter applies this idea to the most common case in machine learning: classification, where the quantity to predict is discrete. The resulting model, the softmax classifier, is everywhere in deep learning: it is the output layer of image classifiers, and also of language models, which are classifiers predicting the next token among a vocabulary of tens of thousands of words.

Classification as density estimation

In classification, we want to learn a mapping between input vectors \mathbf{x} and a finite number K of classes. In object recognition, the inputs are the pixels of images, and the classes are the names of the objects they represent. The training data is a set of pairs \{(\mathbf{x}_i, \mathbf{t}_i)\}_{i=1}^N, where the targets \mathbf{t}_i (also called labels or ground truth) indicate the class of each input.

In multi-class classification, the target is usually represented by a one-hot encoded vector: a vector of K zeros, except a one at the position of the correct class. For example, with five classes (cat, dog, ship, house, car), an image of a dog is associated with the target:

\mathbf{t} = [\text{cat}, \text{dog}, \text{ship}, \text{house}, \text{car}] = [0, 1, 0, 0, 0]

This vector can be read in a probabilistic way: it is a categorical distribution over the classes (a die with one face per class, Sampling from simple distributions), which puts all its probability on the class “dog”:

p(\mathbf{t} | \mathbf{x}) = [p(\text{cat}| \mathbf{x}), p(\text{dog}| \mathbf{x}), p(\text{ship}| \mathbf{x}), p(\text{house}| \mathbf{x}), p(\text{car}| \mathbf{x})] = [0, 1, 0, 0, 0]

The targets of the training set are therefore samples of an unknown conditional distribution p(\mathbf{t} | \mathbf{x}): the probability of each class, given the input. One-hot vectors are only a special case of this distribution, where the class is certain. The targets could perfectly be “soft”, for example [0.1, 0.7, 0, 0, 0.2] for an ambiguous image, or when several annotators disagree.

Classification thus becomes a density estimation problem, as in Kullback-Leibler divergence in machine learning: we want a parameterized model p_\theta(\mathbf{t} | \mathbf{x}) that outputs, for each input, a categorical distribution as close as possible to the one of the data.

The softmax function

A neural network F_\theta can easily output a vector of K real numbers for each input. These numbers are called the logits \mathbf{z}:

\mathbf{z} = F_\theta(\mathbf{x})

The logits can take any real value, so they cannot be used directly as probabilities, which must be positive and sum to one. The softmax function \mathcal{S} transforms them into a categorical distribution \mathbf{y}:

y_k = \mathcal{S}(\mathbf{z})_k = \dfrac{\exp z_k}{\sum_{l=1}^K \exp z_l}

The exponential makes all elements positive, and the denominator normalizes them so that they sum to one (Figure 8.1). The output \mathbf{y} of the network is the model distribution p_\theta(\mathbf{t} | \mathbf{x}): its element y_k is the predicted probability of the class k.

A few properties help to understand what the softmax does:

  • It preserves the ranking of the logits: the class with the highest logit gets the highest probability.
  • It only depends on the differences between the logits: adding the same constant to all logits does not change the probabilities, as the factor \exp c cancels between the numerator and the denominator. Libraries use this property to compute the softmax in a numerically stable way, by subtracting the largest logit first.
  • It is a smooth version of the argmax: if one logit is much larger than the others, the softmax puts almost all the probability on this class. Dividing the logits by a temperature T before the softmax controls this behavior: a low temperature (T \rightarrow 0) gives a one-hot vector on the most likely class, a high temperature (T \rightarrow \infty) a uniform distribution.

The cross-entropy loss

We now have two categorical distributions for each input: the target \mathbf{t}, representing the data, and the prediction \mathbf{y}, representing the model. As in Kullback-Leibler divergence in machine learning, we want to minimize the KL divergence between them, which is the same as minimizing their cross-entropy (Cross-entropy), as the entropy of the data does not depend on the parameters:

\mathcal{L}(\theta) = \mathbb{E}_{(\mathbf{x}, \mathbf{t}) \sim \mathcal{D}} [H(p(\mathbf{t} | \mathbf{x}), p_\theta(\mathbf{t} | \mathbf{x}))] = \mathbb{E}_{(\mathbf{x}, \mathbf{t}) \sim \mathcal{D}} [- \sum_{k=1}^K t_k \, \log y_k]

The cross-entropy between two categorical distributions is a sum over the classes, which can be written as a dot product: - \mathbf{t} \cdot \log \mathbf{y}. With a one-hot target, all terms of the sum are zero except the one of the correct class. For the image of a dog:

- \mathbf{t} \cdot \log \mathbf{y} = - \begin{bmatrix} 0 & 1 & 0 & 0 & 0 \\ \end{bmatrix} \cdot \begin{bmatrix} \log \, p_\theta(\text{cat}| \mathbf{x}) \\ \log \, p_\theta(\text{dog}| \mathbf{x}) \\ \log \, p_\theta(\text{ship}| \mathbf{x}) \\ \log \, p_\theta(\text{house}| \mathbf{x})\\ \log \, p_\theta(\text{car}| \mathbf{x}) \\ \end{bmatrix} = - \log \, p_\theta(\text{dog}| \mathbf{x})

The loss of a single example is simply the negative log-likelihood of the correct class under the model: we recover maximum likelihood estimation (Maximum likelihood estimation). Its behavior is easy to interpret:

  • if the model is confident and right (p_\theta(\text{dog}| \mathbf{x}) \approx 1), the loss is close to zero;
  • if the model is uncertain (p_\theta(\text{dog}| \mathbf{x}) = 1/K, the uniform distribution), the loss is \log K;
  • if the model is confident and wrong (p_\theta(\text{dog}| \mathbf{x}) \approx 0), the loss is very large: confident mistakes are heavily penalized.

In practice, the expectation is estimated on the training set, or on a minibatch of it, with a Monte Carlo average (The Monte Carlo estimator):

\mathcal{L}(\theta) \approx \dfrac{1}{N} \sum_{i=1}^N - \mathbf{t}_i \cdot \log \mathbf{y}_i

The gradient of the loss

To minimize the loss with gradient descent, we need its gradient with respect to the parameters \theta. By the chain rule, it goes through the logits \mathbf{z} = F_\theta(\mathbf{x}), and the combination of the logarithm in the cross-entropy and of the exponential in the softmax makes the gradient with respect to the logits remarkably simple. For a single example with loss l(\theta) = - \mathbf{t} \cdot \log \mathbf{y}:

\dfrac{\partial l(\theta)}{\partial \mathbf{z}} = - (\mathbf{t} - \mathbf{y})

NoteProof

When differentiating a softmax probability y_l = \dfrac{\exp z_l}{\sum_m \exp z_m} with respect to a logit z_k, two cases have to be considered:

  • If l = k, \exp z_k appears both in the numerator and in the denominator. The product rule (f\times g)' = f'\, g + f \, g' gives us:

\begin{aligned} \dfrac{\partial y_k}{\partial z_k} &= \dfrac{\exp z_k}{\sum_m \exp z_m} + \exp z_k \, \dfrac{- \exp z_k}{(\sum_m \exp z_m)^2} \\ &= \dfrac{\exp z_k \, \sum_m \exp z_m - (\exp z_k)^2}{(\sum_m \exp z_m)^2} \\ &= \dfrac{\exp z_k}{\sum_m \exp z_m} \, (1- \dfrac{\exp z_k}{\sum_m \exp z_m})\\ &= y_k \, (1 - y_k)\\ \end{aligned}

This is similar to the derivative of the logistic function.

  • If l \neq k, z_k only appears in the denominator, so we only need the chain rule:

\begin{aligned} \dfrac{\partial y_l}{\partial z_k} &= - \exp z_l \, \dfrac{\exp z_k}{(\sum_m \exp z_m)^2} \\ &= - \dfrac{\exp z_k}{\sum_m \exp z_m} \, \dfrac{\exp z_l}{\sum_m \exp z_m} \\ &= - y_k \, y_l \\ \end{aligned}

This allows us to differentiate the cross-entropy:

\begin{aligned} \frac{\partial l(\theta)}{\partial z_k} & = - \sum_l \frac{\partial}{\partial z_k} t_l \log y_l = - \sum_l t_l \frac{\partial \log y_l}{\partial z_k} = - \sum_l \frac{t_l}{y_l} \frac{\partial y_l}{\partial z_k} \\ & = - \frac{t_k}{y_k} \frac{\partial y_k}{\partial z_k} - \sum_{l \neq k} \frac{t_l}{y_l} \frac{\partial y_l}{\partial z_k} = - \frac{t_k}{y_k} y_k (1-y_k) - \sum_{l \neq k} \frac{t_l}{y_l} (-y_l \, y_k) \\ & = - t_k + t_k \, y_k + \sum_{l \neq k} t_l \, y_k = - t_k + y_k \sum_{l} t_l \\ & = - (t_k - y_k) \end{aligned}

as the targets sum to one.

The gradient with respect to the logits is the prediction error: the difference between the target and the predicted distribution. This is the same form as the gradient of the mean square error in linear regression, which makes the softmax classifier as easy to train as a regression model:

  • the logit of the correct class (t_k = 1) is increased by 1 - y_k, i.e. a lot if the model gives it a low probability, and not at all if the model is already certain;
  • the logits of the wrong classes (t_k = 0) are decreased by y_k, i.e. in proportion of the probability the model wrongly gives them;
  • when the prediction matches the target, \mathbf{y} = \mathbf{t}, the gradient is zero.

The gradient with respect to the parameters is then obtained by backpropagating this error through the network:

\nabla_\theta \, \mathcal{L}(\theta) = \mathbb{E}_{(\mathbf{x}, \mathbf{t}) \sim \mathcal{D}} [ - (\mathbf{t} - \mathbf{y} ) \times \nabla_\theta \, F_\theta(\mathbf{x})]

The network F_\theta can be anything differentiable: whatever its architecture, training it with the cross-entropy loss minimizes the KL divergence between the categorical distribution of the data and the one of the model.

Using the predicted distribution

Once trained, the classifier outputs a full probability distribution over the classes, which can be used in two ways:

  • For decisions, we usually keep the most probable class, the argmax of \mathbf{y}, as the prediction of the classifier.
  • For generation, we can sample a class from the categorical distribution \mathbf{y} (Sampling from simple distributions). This is how language models generate text: at each step, the next token is sampled from the softmax output, and the temperature of the softmax controls the trade-off between the most likely continuations (T \rightarrow 0, close to the argmax) and more diverse ones (larger T).

The predicted probabilities also quantify the confidence of the model, but only to a certain extent: a classifier trained with the cross-entropy loss can be confidently wrong on inputs that are very different from its training data. The softmax only represents the uncertainty that is present in the data themselves (ambiguous inputs), not the uncertainty of the model about its own parameters.
